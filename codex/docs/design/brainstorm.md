# AIGX 原创增强方向

以下方向不作为 P0 承诺，按技术价值和现有 Rust 架构优势排序。

1. **Hedged Requests**：并行请求两个健康渠道，首个可接受响应胜出，取消其余请求；需定义额外成本上限和流式响应仲裁。
2. **实时渠道竞速面板**：展示同一请求的渠道首 token、总延迟、错误和胜出率，帮助运营调权。
3. **渠道自动调优**：根据延迟、成功率、质量反馈和成本自动调整权重，并保留人工锁定。
4. **故障自愈时间线**：把熔断、探活、恢复、重试和权重变化串成可审计时间线。
5. **缓存节省看板**：按租户、模型、渠道展示缓存命中量与节省金额。
6. **请求成本模拟器**：发送前根据估算 token、模型价格、缓存命中概率给出成本区间，并提示预算风险。
7. **GraphQL 自定义运营面板**：在现有 GraphQL 能力之上提供受限查询模板和导出，避免为每个指标增加页面。
8. **意图层路由**：先识别代码、翻译、总结、视觉、长上下文等意图，再结合模型能力和价格路由。
9. **微支付流式计费**：将长响应拆为可结算片段，探索按 token 或按结果质量支付。
10. **渠道对战实验**：同一 prompt 在多个渠道 A/B，对延迟、成本、结构化正确率和人工评分做对比。

## 评估门槛

每个方向进入开发前必须明确：用户收益、额外成本、数据采集、失败降级、权限边界、可关闭开关和回滚方案。涉及并行请求或支付的功能必须先完成预算保护与审计日志。
