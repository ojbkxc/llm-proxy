# AIGX 升级路线图

## 目标

将 AIGX 从渠道管理与调试工具升级为具备稳定计费、可观测路由和高质量聊天体验的 AI 工作台。所有阶段采用可回滚、可观测、兼容 OpenAI API 的增量发布方式。

## P0：核心闭环

### 后端

- 计费预扣、上游结算、失败退款与缓存差异计费，全部幂等。
- TOTP 2FA、会话列表、会话撤销与并发会话上限。
- 渠道模型元数据同步与缺失模型检测。
- 将现有 prober 统一为管理 API，支持手动连通性测试。
- 暴露 request id、渠道、模型、延迟、用量、错误分类等核心指标。

### 前端

- ChatCenter：新建会话、流式消息、停止、重试、复制、编辑。
- 会话持久化、搜索、置顶和删除确认。
- Settings 拆分为 General / Interface / Account / Security / Notifications。
- system/light/dark 主题和统一设计 token。
- 基础组件补齐 loading、empty、error、disabled、focus、移动端状态。

### P0 验收标准

- 新用户可在 3 分钟内完成登录、选模型、发送消息并看到流式响应。
- 上游超时、重试、重复回调不会造成重复扣费；账务可通过 request id 对账。
- 管理员可测试渠道连通性，并查看模型同步与失败原因。
- 键盘操作可完成核心聊天流程，桌面/移动宽度下无横向溢出。
- 明暗主题切换通过自动化截图或人工检查确认主要页面对比度合格。

## P1：体验跃迁

### 后端

- 优先新增 10–15 个渠道适配器。
- Embedding、Rerank、Image API 及 capability 声明。
- 通用 OIDC、模型预设、成本模拟所需的价格查询接口。
- 成本、缓存节省、故障时间线和渠道质量数据看板。

### 前端

- Completions Playground，支持参数、系统提示与请求体检查。
- slash command、`@model`、附件入口、Markdown/代码块增强、思考过程折叠。
- 模型预设、缓存节省看板、请求成本模拟器。

### P1 验收标准

- 新增 API 均有契约测试、错误码说明和能力不支持时的明确提示。
- 管理员能按模型/租户/渠道查看成本、延迟、错误率与缓存节省。
- Playground 的参数可保存为预设，并可从 ChatCenter 直接调用。

## P2：扩展能力

- 通用异步任务框架，以及视频、音乐等任务适配器。
- Realtime WebSocket、RAG 知识库、引用、Artifacts 画布。
- 会话文件夹/标签、分享链接、语音输入、意图层路由、hedged requests。
- 在规模确有需要时评估 ClickHouse；单体部署默认不引入额外基础设施。

### P2 验收标准

- 异步任务具备 submit/poll/cancel、超时、重试、幂等和账务闭环。
- RAG 的来源、权限、删除传播和引用可审计。
- 高成本实验能力均有预算上限、租户开关、指标和一键回滚。

## 发布与质量门禁

- 每阶段先在 feature flag 下灰度，记录迁移脚本和回滚步骤。
- 服务端完成格式化、静态检查、单元/集成测试；前端完成类型检查、构建和关键流程 E2E。
- 任何计费、认证、路由策略变更必须有审计日志和兼容性说明。
